# Task: Mehrere Visualisierungsmodi

Dieser Ordner enthält den späteren Umsetzungsauftrag für mehrere
Visualisierungsarten auf derselben `graph-universe`-JSON.

- [ROADMAP.md](ROADMAP.md) beschreibt die abhängigen Umsetzungsslices,
  Akzeptanzkriterien und Prüfungen.
- [Konzeptdokument](../../docs/08-Mehrere-Visualisierungsmodi.md) enthält die
  fachliche Zielidee.
