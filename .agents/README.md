# Agentenregeln

Die Regeln unter `rules/` sind Projektinfrastruktur. Sie halten agentische Änderungen klein, lesbar, testbar und nachvollziehbar.

`AGENTS.md` im Repository-Root ist der Einstiegspunkt. Neue Regeln sollen nur ergänzt werden, wenn sie ein wiederkehrendes Problem konkret verhindern oder eine deterministische Prüfung ermöglichen.
